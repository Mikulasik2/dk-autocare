Sem sa budú vkladať reálne fotografie D&K AutoCARE:

- hero.jpg           -> fotografia pre pozadie hero sekcie (voliteľné, pozri index.html komentár v .hero-bg)
- gallery/            -> fotografie realizácií pre sekciu Galéria (pozri gallery/README.txt pre presné názvy súborov a návod)

Odporúčané formáty: .jpg alebo .webp, optimalizované pre web (do cca 300-500 KB na fotografiu).
